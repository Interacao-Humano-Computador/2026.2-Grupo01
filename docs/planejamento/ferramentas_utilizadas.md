## Ferramentas escolhidas e utilizadas

Abaixo estão descritas as ferramentas de software que foram utilizadas ao longo do projeto e as Entregas nas quais foram empregadas.

| Ferramenta | Descrição e Finalidade no Projeto | Entregas em que foi Utilizada |
| :--- | :--- | :--- |
| **GitHub** | Controle de versão e repositório centralizado de arquivos. Utilizado para gerenciar o histórico de modificações, organizar tarefas (*issues*) e manter o código e os documentos da equipe sincronizados. | |
| **WhatsApp** | Canal de comunicação rápida e assíncrona. Utilizado para avisos urgentes, tomadas de decisão imediatas e coordenação diária entre os membros do grupo. | |
| **Microsoft Teams** | Plataforma de reuniões e videoconferências. Utilizada para a realização das reuniões síncronas de planejamento, alinhamento técnico e discussões aprofundadas dos artefatos. | |
| **When2meet** | Sítio online de coordenação e agendamento de compromissos. Utilizado para mapear e cruzar graficamente a disponibilidade de horários de todos os membros da equipe, facilitando a marcação das reuniões síncronas. | |
| **YouTube** | Hospedagem e compartilhamento de apresentações multimídia. Utilizado para publicar os vídeos de apresentação das entregas da equipe sob a categoria "Não Listado", conforme as exigências do professor. | |
| **MkDocs** | Gerador de documentação estática em Markdown. Utilizado para estruturar e organizar o conteúdo teórico, metodológico e prático do projeto em formato de site informativo. | |
| **Google Docs** | Processador de textos colaborativo em nuvem. Utilizado para a redação síncrona dos relatórios, listas de verificação, planos de avaliação e revisões textuais entre os integrantes. | |
| **GitHub Pages** | Hospedagem da Wiki do projeto. Utilizado para publicar e disponibilizar na web o site gerado pelo MkDocs contendo todo o histórico de desenvolvimento da equipe. | |
| **Gemini** | Assistente de inteligência artificial generativa. Utilizado para apoiar a equipe no refinamento linguístico, elaboração de ideias de design e revisão ortográfica dos textos de entrega. | |
| **Gemini Notebook** | Workspace inteligente baseado em fontes científicas. Utilizado para analisar criticamente os conceitos da disciplina, garantir a fundamentação bibliográfica e verificar o alinhamento ético (LGPD) e metodológico (DECIDE) do projeto. | |
| **Google Forms** | Ferramenta de questionários on-line. Utilizada para a criação de pesquisas de perfil de usuário ou consolidação de checklists de inspeção de forma digitalizada. | |
| **Figma** | Software de design de interfaces e prototipagem colaborativa. Utilizado para a execução de wireframes, guias de estilo visuais e desenvolvimento dos protótipos interativos de baixa e alta fidelidade. | |
| **VS Code** | Editor de código-fonte e texto. Utilizado na escrita e edição local dos arquivos Markdown, folhas de estilo (CSS) do MkDocs e demais scripts do projeto. | |

### Declaração de Uso de IA Generativa

Em conformidade com o Código de Conduta da Sociedade Brasileira de Computação (SBC), em sua Parte II, Art. 2º, parágrafo III, informa-se que a ferramenta de Inteligência Artificial Generativa Gemini e Gemini Notebook foram utilizados neste trabalho. As ferramentas foram empregadas exclusivamente para as atividades de auxílio e revisão da redação do conteúdo textual. Ressalta-se que o uso desta tecnologia não exime os autores da responsabilidade integral sobre todo o conteúdo do projeto.
