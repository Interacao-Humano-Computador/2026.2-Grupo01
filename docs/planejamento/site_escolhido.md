## Introdução:

Inicialmente, o grupo procurou por sites governamentais que possuíssem funcionalidades e problemas de IHC suficientes para o número de integrantes do grupo, porém foi encontrado muita dificuldade para encontrar um sistema que atendesse a estes critérios, e que também não tivessem sido avaliados por grupos passados da mesma disciplina. 

Desta forma, a alternativa do grupo foi buscar sistemas e comunidades de código aberto, uma vez que os mesmos atendem a critérios estabelecidos pelo professor, de poder aplicar engenharia reversa, os direitos autorais permitirem o uso na disciplina, e também, os critérios da equipe, de possuir funcionalidades e problemas de IHC a serem explorados, além de facilidade de encontrar usuários do sistema.

## Motivação de escolha

Inicialmente, foi apresentaodo o projeto de código aberto <a href="https://openlibrary.org/">OpenLibrary</a>, que atendia a todos os critérios estabelecidos pelo professor e pelo grupo, porém conforme a equipe se organizava para iniciar o planejamento da avaliação, foi sugerido por outro integrante do grupo, o projeto, também de código aberto <a href="https://www.oppia.org/">Oppia</a>.

O grupo discutiu as funcionalidades, usuários, problemas de IHC e chegou a conclusão que o sistema **Oppia** possui mais funcionalidades a serem exploradas e maiores problemas de IHC a serem avaliados, sendo assim definido para a execução de IHC do semestre.
