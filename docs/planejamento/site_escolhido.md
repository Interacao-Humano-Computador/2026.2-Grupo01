# Site Escolhido

## 1. Introdução

Inicialmente o grupo procurou por sites governamentais que possuíssem funcionalidades e problemas de IHC suficientes para o número de integrantes do grupo, porém foi encontrado muita dificuldade para encontrar um sistema que atendesse a estes critérios, e que também não tivessem sido avaliados por grupos passados da mesma disciplina. 

Desta forma, a alternativa do grupo foi buscar sistemas e comunidades de código aberto, uma vez que estes atendem aos critérios estabelecidos pelo professor — a possibilidade de aplicar engenharia reversa e a permissão dos direitos autorais para uso na disciplina — bem como aos critérios da equipe, de possuir funcionalidades e problemas de IHC a serem explorados, além de facilidade para encontrar usuários do sistema.

Porém, foi necessário, após a Entrega 1 do projeto, trocar o site devido às dificuldades em encontrar usuários acessíveis que utilizam o sistema anteriormente escolhido.

## 2. Motivação de Escolha

Inicialmente, foi apresentado o projeto de código aberto <a href="https://openlibrary.org/">OpenLibrary</a>, que atendia a todos os critérios estabelecidos pelo professor e pelo grupo. Porém, conforme a equipe se organizava para iniciar o planejamento da avaliação, foi sugerido por outro integrante do grupo o projeto, também de código aberto, <a href="https://www.oppia.org/">Oppia</a>.

O grupo discutiu as funcionalidades, os usuários e os problemas de IHC envolvidos e chegou à conclusão de que o sistema **Oppia** possui mais funcionalidades a serem exploradas e maiores problemas de IHC a serem avaliados, sendo assim definido para a execução da avaliação de IHC da Entrega 1.

Entretanto, durante a Entrega 2, o grupo percebeu que os usuários do sistema não eram tão acessíveis para o nível de proximidade que o projeto exige. Então foi necessário uma nova conversa para definir um substituto que ainda possuísse como critérios mínimos a questão de funcionalidades e problemas de IHC em número satisfatório para a equipe trabalhar e ser de uso mais difundido na sociedade em geral.

Uma integrante do grupo sugeriu o Microsoft Teams <a href="https://www.microsoft.com/pt-br/microsoft-teams/download-app">Microsoft Teams</a>, pelo seu amplo uso na Administração Pública, no ambiente corporativo e em universidades. Com isso, foi colocado em votação e a maioria do grupo decidiu pela troca do site escolhido.
