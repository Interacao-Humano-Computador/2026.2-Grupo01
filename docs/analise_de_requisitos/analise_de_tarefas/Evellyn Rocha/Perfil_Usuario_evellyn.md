# 1. Perfil de Usuário — Microsoft Teams

## 1.1. Perfil de Usuário

De acordo com a Seção 6.1 do livro *Interação Humano-Computador*, a elaboração do perfil de usuário é uma etapa importante para compreender quem são os usuários do sistema, quais são suas características, seus objetivos e suas necessidades. Esse levantamento considera aspectos como faixa etária, nível de instrução, experiência com tecnologia, frequência de uso e atividades realizadas.

Essas informações auxiliam a equipe de projeto a compreender o público para o qual a solução está sendo desenvolvida e servem como base para a elaboração de personas.

**Fonte:** Livro *Interação Humano-Computador*, Seção 6.1, páginas 175 e 176.

### 1.1.2. Síntese do perfil

O perfil considerado corresponde a um estudante universitário jovem, com familiaridade com tecnologia e utilização frequente do Microsoft Teams como ferramenta de apoio às atividades acadêmicas. É um usuário que aprende com facilidade e consegue explorar os recursos da plataforma de maneira relativamente independente.

No contexto da funcionalidade analisada, seu principal objetivo é acessar o canal da disciplina, localizar uma atividade, compreender as instruções, realizá-la e confirmar sua entrega. Dessa forma, a interface deve favorecer a organização das informações, a localização das atividades e a clareza dos retornos apresentados pelo sistema.

**Observação metodológica:** este perfil é uma caracterização preliminar construída a partir das informações disponíveis para o projeto. As características e possíveis dificuldades deverão ser validadas ou ajustadas caso sejam realizadas entrevistas, questionários ou outras atividades de coleta de dados com estudantes.

# 2. Aspectos Éticos e Termos de Consentimento

Em conformidade com as diretrizes éticas para pesquisas envolvendo seres humanos em IHC (Barbosa e Silva, 2010; ANPD, 2023), foram assegurados os princípios de autonomia, beneficência, privacidade e voluntariedade dos participantes.

Para a execução tanto das entrevistas quanto do grupo de foco, foram elaborados e aplicados Termos de Consentimento Livre e Esclarecido (TCLEs) específicos.

Antes de iniciar cada atividade de coleta de dados, os participantes receberam informações claras sobre a finalidade acadêmica da pesquisa, a garantia de anonimato dos dados coletados e a liberdade de cancelar sua participação a qualquer momento, formalizando a autorização prévia para gravação e análise das respostas.
